Settings

Index import

Accepts the library index format (INDEXER_PLAN.md §2): one _meta header line, tag dictionary rows, then compact gallery rows — plain or gzipped .jsonl. The index is stored in the extension's OPFS, never in chrome.storage.local (that store is small and capped). Re-importing a source replaces that source only.

Watches

A watch is a saved tag combination (e.g. vanilla + english) with a one-click refresh: it walks each tag's newest listings on the source's documented API — sequentially, one page at a time, politely rate-limited — and stops at the first title the index already knows, merging only genuinely new titles. New titles carry a NEW badge in Browse until you clear them. Refreshes never run in parallel, and a rate limit stops the refresh with words instead of retrying.

Downloads

Off (default) keeps your browser's own download behavior untouched. On, every archive this extension hands to Chrome lands directly in the download folder without the prompt.

Size estimate

Used for the rough size estimate in the selection bar — not a promise about any one title. The panel's download history is a better source for what your mirrors actually average.

Thumbnail cache

In the cached mode, covers you have browsed are kept in the extension's OPFS under this cap (least-recently-used is evicted first): the next view serves them from disk, instantly, even with no internet. Keeping them needs the CDN host grant (the panel's CDN notice); without it covers still display live from the site — nothing is bypassed, nothing breaks. Live-only mode never reads or writes the cache, but keeps stored covers, so switching back restores them.
