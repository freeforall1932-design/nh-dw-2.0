Global behaviour

Download format:
ZIP / CBZ = one archive file containing the original images. PDF = one PDF file with one image per page; images are embedded without re-compression, so quality stays the same and the size is about the same as all images together. Raw = each image downloaded separately (no archive).
Folder for raw downloads:
Only used by the Raw format: each gallery's loose pages go into a folder named after the title, inside this master folder — e.g. Downloads\NHDW\<gallery title>\001.jpg — so hundreds of galleries stay grouped in one place instead of flooding your download folder. Empty the box to put each gallery folder straight into the download folder. Tip: a value with slashes nests deeper ("NHDW/raw" → Downloads\NHDW\raw\<title>).

Behaviour on duplicate:
What happens when a batch contains two galleries with the same title. Rename = keep both files: the gallery ID is added to the duplicate's file name, e.g. "Title (123456)". Ignore = skip the duplicate: it is not downloaded again, and the file already downloaded stays exactly as it is (nothing is replaced).
Download each file separately:
Off = all selected galleries go into one shared archive. On = each gallery gets its own archive file named after its title.

Optional nhentai API key

Optional. Downloads work without a key. Paste a key you generated in your nhentai account settings; this extension never asks for your password or creates keys. The key is kept in this browser profile only and is not synced. It stays saved across browser restarts and disabling/re-enabling the extension; only Remove key (or uninstalling the extension) removes it.


To paste: click the box, then press Ctrl+V (pasting is supported even where the right-click menu is not available).

Download whole galleries as one ready-made file from the server (requires API key):
When on, the extension asks the nhentai server for the complete gallery as one ZIP/CBZ file instead of fetching every page itself — usually faster. If the server does not offer this for your account, the extension quietly falls back to downloading page by page, so nothing breaks. Applies to ZIP/CBZ downloads of single galleries (not PDF, not raw).
