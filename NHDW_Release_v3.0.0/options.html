API access (optional)

nhentai API key:

Generate a key on nhentai.net → account settings → API keys. With a key, metadata resolves through the official API (higher rate limits). Without a key, metadata is read from your open NHentai tab. The key is stored only in this browser.
Use one-shot server archive downloads when available (requires API key):
Experimental: asks POST /api/v2/galleries/<id>/download for a ready-made ZIP/CBZ instead of fetching every page. Falls back to page-by-page automatically when unavailable. Applies to ZIP/CBZ format and single-gallery archives only.
