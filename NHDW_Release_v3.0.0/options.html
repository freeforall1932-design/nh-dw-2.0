Global behaviour

Download format:
ZIP / CBZ = one archive file containing the original images. PDF = one PDF file with one image per page; images are embedded without re-compression, so quality stays the same and the size is about the same as all images together. Raw = each image downloaded separately (no archive).
Folder for raw downloads:
Only used by the Raw format: each gallery's loose pages go into a folder named after the title, inside this master folder — e.g. Downloads\NHDW\<gallery title>\001.jpg — so hundreds of galleries stay grouped in one place instead of flooding your download folder. Empty the box to put each gallery folder straight into the download folder. Tip: a value with slashes nests deeper ("NHDW/raw" → Downloads\NHDW\raw\<title>).

Behaviour on duplicate:
What happens when a batch contains two galleries with the same title. Rename = keep both files: the gallery ID is added to the duplicate's file name, e.g. "Title (123456)". Ignore = skip the duplicate: it is not downloaded again, and the file already downloaded stays exactly as it is (nothing is replaced).
Download each file separately:
Off = all selected galleries go into one shared archive. On = each gallery gets its own archive file named after its title. This is the legacy global switch; list mode below has its own, more explicit output-mode setting that overrides it.

List mode (homepage, search, artist, tag, genre)

Used by the listing panel, the in-page card buttons and Download all. These are stored separately from the single-title settings above, so changing one never changes the other.

Format:
The same four formats a single title offers. Raw writes loose images into one folder per title.
Output:
Separate files is the default: one archive (or one folder, for raw) per title, named from the list-mode template below. Single merged file is the old behaviour - every selected gallery goes into one archive. Merging several different titles into one PDF produces a tankoubon-style document that cannot be split afterwards, so that combination always asks for confirmation first.
Put list downloads in the master folder:
Optional, not forced. When ticked, list downloads land in the folder named above ("Folder for raw downloads") - archives as Downloads\NHDW\<name>.zip and raw pages as Downloads\NHDW\<title>\001.jpg. Untick it to save straight into the download folder.
List-mode file name:
Same tokens as the single-title template ({pretty}, {english}, {japanese}, {id}, {artist}, {group}, {character}, {language}). Leave it empty to follow the single-title template. Resolved per gallery from that gallery's own metadata - never from the page URL.

Interface

Toolbar click opens:
The side panel docks next to the page, can be resized and stays open while you browse; the popup closes as soon as it loses focus. Both show exactly the same view.
Download / Select buttons on listing cards:
Adds a Download button and a Select box to every gallery card, plus a floating bar showing the selection count, format and output mode - so listing pages can be downloaded without opening the extension at all. Reload the nhentai page after changing this.

Optional nhentai API key

Optional. Downloads work without a key. Paste a key you generated in your nhentai account settings; this extension never asks for your password or creates keys. The key is kept in this browser profile only and is not synced. It stays saved across browser restarts and disabling/re-enabling the extension; only Remove key (or uninstalling the extension) removes it.


To paste: click the box, then press Ctrl+V (pasting is supported even where the right-click menu is not available).

Download whole galleries as one ready-made file from the server (requires API key):
When on, the extension asks the nhentai server for the complete gallery as one ZIP/CBZ file instead of fetching every page itself — usually faster. If the server does not offer this for your account, the extension quietly falls back to downloading page by page, so nothing breaks. Applies to ZIP/CBZ downloads of single galleries (not PDF, not raw).

Download history

Galleries downloaded successfully are remembered in this browser (never synced) and skipped on listing pages, so re-running a search, tag, artist or homepage does not download everything a second time. Each already-downloaded row in the panel has its own Download anyway link; this button forgets the whole list (the per-row override stops working, and everything downloads again).
